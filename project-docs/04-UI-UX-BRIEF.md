# DIASA UI/UX Brief

Use a restrained enterprise operations interface: navy navigation, pale operational canvas, white work panels, red emergency accent, blue action accent, compact typography, strong focus states, and responsive layouts.

Public reporting prioritizes clarity and low cognitive load. Administrators need scan-friendly KPIs, severity/status badges, realtime freshness, search, filters, confirmation before destructive actions, and readable detail views.

Every asynchronous surface needs loading, empty, success, and error states. Decorative controls are prohibited. Coordinate and map controls must clearly communicate whether a location is manually entered, verified, or unavailable.
